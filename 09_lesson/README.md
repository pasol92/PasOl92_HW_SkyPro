# Домашнее задание 9: Автотесты для БД

## Описание
В этом проекте реализованы тесты на Python для проверки базы данных PostgreSQL. 
Тесты проверяют операции CRUD: добавление записей, их обновление и удаление (с очисткой тестовых данных).

## Инструменты
* pytest
* SQLAlchemy
* psycopg2

## Как запустить проект
1. Активируйте виртуальное окружение: `source venv/bin/activate`
2. Запустите тесты командой: `pytest`
